## 1\. Project Overview

Hadara is an emerging South African modest fashion brand founded by Hadassah Tshaka. The website serves as an online catalog, information portal, and client inquiry terminal for Christian women and families seeking elegant, feminine, high-quality, and modest apparel (casual wear, evening gowns, and little girls' collections).

### Key Pages:

* `index.html` — Home page, hero introduction, brand statement, and quick facts.  
* `about.html` — Brand history, founder profile, and core values (Modesty, Elegance, Faith, Quality, Femininity).  
* `products.html` — Interactive garment catalog featuring live client-side search filtering and image lightbox views.  
* `enquiry.html` — Form for custom dress orders, size inquiries, and mother-daughter sets.  
* `contact us.html` — General inquiries form and brand contact information.

---

## 2\. Technical Architecture & Specifications

* **Frontend:** Semantic HTML5, Modular CSS3 (Flexbox and Grid layout), Vanilla JavaScript (ES6+).  
* **Typography & Styling:** Playfair Display, luxury neutral color palette (Deep Brown `#4A3426`, Mocha `#7A5A44`, Wheat `#D4B27A`, Cream `#F7F4EE`, Soft Beige `#E8E1D4`).  
* **SEO Implementation:**  
  * Unique `<title>` and `<meta name="description">` tags for every HTML page.  
  * Structural SEO files: `robots.txt` and `sitemap.xml`.  
  * Open graph structure and descriptive `alt` tags on responsive image elements.  
* **Version Control:** Hosted on GitHub with regular structured commit histories.

---

## 3\. Part 3 Implementations & Features

1. **Interactive Product Search:** Live filtering algorithm integrated into `products.html` to instantly sort clothing items by title and description.  
2. **Lightbox Gallery Modal:** Dynamic DOM manipulation enabling click-to-enlarge modal popups for all catalog images.  
3. **Client-Side Form Validation:** Asynchronous JavaScript checking and user feedback handling on both `enquiry.html` and `contact us.html`.  
4. **Technical SEO Infrastructure:** Crawling directives mapped in `robots.txt` and sitemap routing in `sitemap.xml`.
